# Recruitment & Placement Management System - UI Prototype

Static HTML + CSS prototype (no backend).

## How to open
1. Extract the folder.
2. Open `login.html` in any browser.
3. Click **Login** to reach the dashboard; use the sidebar to move between pages.

## Structure
12 HTML pages in the root, shared stylesheet in `css/style.css`, logo in `images/logo.png`.
